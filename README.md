### 🧠 PokéBrain AI  
Agente intelligente progettato per affrontare avversari nel simulatore **Pokémon Showdown**, basato sull’algoritmo **Minimax**.  
🔧 **Tecnologie**: AI, search tree  
🧩 Struttura ad albero degli stati di gioco, con valutazione basata su:  
- danni subiti,  
- danni inflitti,  
- efficacia delle mosse.

🎯 **Obiettivo**: prevedere le mosse dell’avversario e migliorare l’efficienza decisionale dell’agente.  
🛠 **Sviluppi futuri**: intendo migliorare l’intelligenza artificiale adottando nuove tecnologie che non si basano sul modello Search Tree, per aumentare precisione ed efficienza.

## Progetto di Tesi individuale
### 🔐 Biometria e IoT (in corso)  
Sistema di riconoscimento facciale per ambienti **IoT**, con focus su sicurezza dei dati biometrici.  
🔧 **Tecnologie**: FaceNet, Fuzzy Extractor, ChaCha20, L2 Distance, Docker, MQTT  
📡 I template biometrici sono cifrati e salvati in un database.  
🎯 **Obiettivo**: sviluppare un sistema sicuro e affidabile per l’autenticazione biometrica basata su riconoscimento facciale, proteggendo i dati sensibili tramite crittografia avanzata.  
Durante l'autenticazione, un nuovo template viene confrontato con quelli memorizzati tramite distanza L2.
